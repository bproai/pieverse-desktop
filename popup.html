API Connection Help

×

To connect to the local API:

  1. Ensure your API server is running on localhost:3030
  2. The API should respond to GET requests at /api/prompts
  3. Response format should match the expected schema

Common issues:

  • Server not running - Check that your local API server has started
  • Wrong port - Verify the server is using port 3030
  • CORS issues - Ensure the API allows CORS with headers: 
    Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST
Access-Control-Allow-Headers: Content-Type
